# no-em-dashes-skill

While loaded, agent-generated text never uses em dashes (U+2014) and avoids semicolons as prose pauses. Retroactive cleanup runs only on scopes the user names explicitly.

See `SKILL.md` for the character table, exceptions, and cleanup rules.

Files: `SKILL.md` (rules), `README.md` (this file), `AGENTS.md` (maintenance contract for editors).
